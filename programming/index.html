三条线的关系

  • C → C++：C++ 的指针、数组、结构体、编译链接这些概念都来自 C。先学 C 再学 C++，你会知道每层抽象下面是什么。
  • C++ → Java：Java 去掉了指针和手动内存管理，代之以引用和垃圾回收。学过 C++ 之后，Java 的“为什么没有析构函数”“为什么对象一定在堆上”都能秒懂。
  • Java → Python：两者的面向对象写法相似，但 Python 更短、更灵活：动态类型、推导式、内置容器。Java 的工程化经验（包、异常、集合）反过来让你写 Python 时更规范。
  • Python 与 C/C++ 的分工：要跑得快、要控制内存、要写数据结构——用 C/C++；要处理数据、写脚本、做实验——用 Python。真实项目里常常两者混用。
