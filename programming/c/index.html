C 语言 学习路线

red wenzi · 2026-09-15 · 编程语言 · C 语言 · 8 章 · 16 道练习

C 是这条学习路线的第一站。它不替你管理内存，也不隐藏任何细节——正因如此，学完 C 再学 C++ 和数据结构，你会知道每一行代码背后机器在做什么。

这门语言可以压成一句话：用指针和结构体，自己组织内存。整条线围绕这一点展开：先把程序跑起来，再搞清楚变量和类型，然后是流程控制、函数、数组与字符串，最后落到指针、动态内存、结构体，用一个统计小项目收尾。

💡 学 C 的正确姿势：每个例子都亲手敲、亲手编译。C 的报错往往比 C++ 更难读，但正因如此，你在这里练出的读报错能力，后面所有语言都用得上。

🛠️ 环境准备

  • Windows：装 MSYS2 或 MinGW-w64，装好后终端里能跑 `gcc --version`。
  • macOS：装 Xcode Command Line Tools（`xcode-select --install`）。
  • Linux：`sudo apt install build-essential`（Debian/Ubuntu 系）。
  • 编译命令统一用：`gcc -std=c17 -Wall -Wextra -o app app.c`。
