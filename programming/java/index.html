Java 学习路线

red wenzi · 2026-09-15 · 编程语言 · Java · 8 章 · 16 道练习

Java 和 C/C++ 是两种不同的取舍：它用**虚拟机 + 垃圾回收**换来了内存安全，用**强类型 + 明确的语言规范**换来了跨平台和工程可维护性。代价是类型大小固定、没有指针、性能调度权交给 JVM。

如果你已经学过 C 或 C++，学 Java 的捷径是抓住差异点：类型大小固定、引用不是指针、对象一定在堆上、字符串不可变、数组带长度检查、异常是强制的。这条线按这个思路组织：程序怎么跑起来 → 类型与字符串 → 流程与数组 → 类与对象 → 继承与接口 → 集合框架 → 异常与文件 → Stream 与实战。

💡 本线代码用 JDK 21 实测（含 record、switch 表达式、Stream 等现代用法）。命令示例里的 javac、java 请确保来自同一套 JDK。

🛠️ 环境准备

  • 装 JDK 17 或 21（推荐 Adoptium Temurin、Oracle JDK、或系统包管理器）。
  • 验证：`javac -version` 与 `java -version` 都能输出且版本一致。
  • 编译运行：`javac -encoding UTF-8 Main.java` 然后 `java Main`。
  • 写代码建议用 VS Code + Extension Pack for Java，或 IntelliJ IDEA。
