第 1 章　第一个 Python 程序与运行环境

red wenzi · 2026-09-15 · 编程语言 · Python · 📖 预计阅读 5 分钟 · 共 2 道练习
🎯 本章你会学到：脚本、REPL、缩进语法，以及 pip / venv 初体验。建议边读边敲，每节练习先自己做，再展开答案对照。

Python 没有编译步骤：写一个 .py 文件，直接用解释器运行；也可以在 REPL 里一行一行试。这种立刻看到结果的循环，是它提高效率的核心。

hello.py
import sys

def main():
    print("Hello, Python")
    print("major version:", sys.version_info.major)

if __name__ == "__main__":      # 直接运行本文件时才执行
    main()
运行结果
Hello, Python
major version: 3
三种常用命令
python hello.py            # 运行脚本
python                     # 进入 REPL（逐行试）
python -m pip install pandas   # 安装第三方库
  • 缩进就是语法：同一层代码必须缩进一致（惯例 4 个空格），缩进错了逻辑就错了。
  • 语句末尾不写分号；声明变量不需要类型，直接 x = 1。
  • if __name__ == "__main__": 用来区分直接运行和被 import——写脚本时养成习惯。
⚠️ 易错点　不要混用 Tab 和空格缩进。编辑器看着对齐，解释器会直接报 IndentationError。
⚠️ 易错点　Python 2 和 Python 3 不是一回事：本线所有代码都要求 Python 3.8 以上。

✍️ 本节练习

1.1必做读一行并回显

读入一行文字，输出 hello, 加上这行文字。

输入　一行文字。

输出　一行 hello, 原内容。

样例输入
world
样例输出
hello, world

💡 提示　input() 读一行并以字符串返回。

✅ 查看参考答案与解析
line = input()
print("hello, " + line)

解析　input() 永远返回字符串；要当数字用必须 int(...) 或 float(...) 转换。

1.2挑战两数之和

读入两个整数（空格分隔），输出它们的和。

输入　一行两个整数 a b。

输出　一行 sum=结果。

样例输入
3 5
样例输出
sum=8

💡 提示　input().split() 按空白切分，map(int, ...) 批量转整数。

✅ 查看参考答案与解析
a, b = map(int, input().split())
print(f"sum={a + b}")

解析　a, b = map(int, ...) 是 Python 处理一行多个数的标准写法，比循环读入更短。
