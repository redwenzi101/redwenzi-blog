Python 学习路线

red wenzi · 2026-09-15 · 编程语言 · Python · 8 章 · 16 道练习

Python 的取舍和前几门都不一样：它用动态类型加缩进语法换来了极短的代码，用解释执行换来了改完立刻跑的手感。代价是运行速度较慢、类型错误要到运行时才暴露。

对已经会 C / C++ / Java 的人来说，Python 最大的价值在把想法快速变成能跑的东西——写脚本、处理数据、做实验。但要注意：动态类型不等于弱类型，变量没有类型标注但值有；1 + "2" 会直接报错而不是偷偷转换。

💡 本线用 CPython 3.12 实测；Windows 上命令可能是 python 或 py，macOS / Linux 上是 python3。

🛠️ 环境准备

  • 装 Python 3.10 以上；Windows 可用 `py` 代替 `python`。
  • 建虚拟环境：`python -m venv .venv`，激活后 `pip install <包名>`。
  • 运行脚本：`python hello.py`；想快速试代码直接敲 `python` 进 REPL。
  • 本线用到的第三方库只有 pandas（第 8 章），其余都是标准库。
