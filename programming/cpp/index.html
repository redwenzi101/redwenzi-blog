📖 怎么用这份教材

每 15~20 分钟完成一个学习单元，四步闭环：

  1. 学（5 分钟）：读知识讲解，碰到“示例代码”就亲手敲一遍，看运行结果是否和文里一致。
  2. 练（10 分钟）：做本节练习。编译报错先自己读 3 分钟，想不出来再看提示。
  3. 对（2 分钟）：展开题目的「查看参考答案与解析」核对；没一次跑通的题记进错题本。
  4. 复盘（每周日）：连续错两次的题，不看答案重写一遍。

过关标准：必做题全部编译运行通过、输出与样例一致，才进入下一节；挑战题做不出来不卡进度，先标记，第 3 天回来重试。
