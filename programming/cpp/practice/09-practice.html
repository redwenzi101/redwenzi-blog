D1创造写程序：用 std::map 存三个城市的人口，用结构化绑定遍历输出“城市: 人口”。

提示：for (const auto& [city, pop] : m)。

✅ 查看答案与解析

答案　参考答案：

解析：结构化绑定让遍历 map 变得非常清爽。数据为示例演示用。

#include <iostream>
#include <map>
#include <string>
int main() {
    std::map<std::string, int> m{{"Jinan", 900}, {"Taiyuan", 530}, {"Shanghai", 2400}};
    for (const auto& [city, pop] : m) {
        std::cout << city << ": " << pop << '\n';
    }
    return 0;
}

A1识别判断题：constexpr 的计算结果可以当数组长度、模板参数用。

A2识别判断题：捕获异常应该按 const 引用（catch (const std::exception& e)）。

✅ 查看答案与解析

答案　B

C1应用改错题：下面想在编译期算阶乘，但写法导致编译错误。
constexpr int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) { result *= i; }  // C++14 后合法，但若用旧标准/写法受限
    return result;
}
✅ 查看答案与解析

答案　C++14 起 constexpr 函数内允许循环。若必须兼容 C++11，用递归：

解析：递归版在任何标准下都能编译期求值；注意 constexpr 函数的调用参数也必须是编译期常量才能编译期算。

constexpr int factorial(int n) { return n <= 1 ? 1 : n * factorial(n - 1); }
D1创造写程序：写一个 divide(a, b)，b == 0 时 throw std::invalid_argument，main 里 try-catch 捕获并输出错误信息。

提示：#include <stdexcept>；catch 用 const 引用。

✅ 查看答案与解析

答案　参考答案：

解析：异常按 const 引用捕获；RAII 写对的话，抛异常不会泄漏资源。

#include <iostream>
#include <stdexcept>
double divide(double a, double b) {
    if (b == 0.0) { throw std::invalid_argument("divide by zero"); }
    return a / b;
}
int main() {
    try {
        std::cout << divide(1.0, 0.0) << '\n';
    }
    catch (const std::invalid_argument& e) {
        std::cout << "caught: " << e.what() << '\n';
    }
    return 0;
}
// 输出：caught: divide by zero
