# 备案通过后：接下来怎么做

> 前提：ICP 备案已经通过。下面按「做了才合规 → 做了才能上线 → 做了才省事」的顺序排。

## 一、你的现状（已确认的部分）

| 项目 | 值 |
|---|---|
| 备案接入商 | **阿里云**（所以站点必须落在阿里云的服务器上） |
| 服务器 | 阿里云 ECS · 青岛 · Ubuntu 22.04 · 安全组要放行 80 / 443 |
| 域名 | `redwenzi.icu`（腾讯云注册，DNS 用 DNSPod） |
| 静态站 | 已在 Cloudflare Pages 跑通（`redwenzi-blog.pages.dev`），70 多个页面 |
| 还缺 | **备案号**（形如 `浙ICP备2026000000号-1`，阿里云控制台 → 备案 → 我的备案里能看到） |

> 注意：域名在腾讯云注册不影响，备案看的是「接入商 + 服务器」——你备案走的是阿里云，就必须用阿里云 ECS 承载。

## 一之二、先定一件事：静态站直出，还是上 WordPress？

你手册里方案 B 写的是装 WordPress。这里有个取舍，建议先看清楚：

| 方案 | 代价 | 何时选 |
|---|---|---|
| **Nginx 直接托管现在这套静态站**（推荐先做） | 零改造，今天就能通；现在这套设计原样上线 | 你现在已经有 70 多个页面成品，视觉也定稿了 |
| 迁到 WordPress | 现在这套首页/课程页设计要重做成 WP 主题，70 多页内容要搬进 CMS，等于重做一遍 | 等你真的需要「网页后台发文」时再做 |

两个不冲突：**先用静态站把备案域名跑起来**，WordPress 作为第二阶段。`DESIGN_TOKENS.md` 里那套色值/圆角本来就是为以后移植 WP 主题留的，到时候直接复用。

## 二、马上要做：页脚挂备案号（工信部硬性要求）

1. 全站页脚展示备案号，并且**必须可以点击跳转到 https://beian.miit.gov.cn/**，只放一行纯文字是不合规的。
2. 本站已经准备好一键脚本，仓库根目录执行：

   ```powershell
   pwsh tools/site-config.ps1 -Icp "浙ICP备2026000000号-1"
   ```

   它会把这 67 处占位（分布在 60 多个页面的页脚，含首页）一次性换成带链接的正确写法。
   加 `-DryRun` 可以先看会改哪些文件。

## 三、30 天内要做：公安联网备案

1. 打开 <https://www.beian.gov.cn>，注册后选「网站备案」，主体信息要和 ICP 备案**完全一致**。
2. 通过后会拿到「公安网备」号（形如 `浙公网安备3301XXXXXXXX号`）。
3. 同样挂到页脚，警徽图标用平台提供的那一张（别自己画）。
4. 时限：一般要求**网站开通后 30 日内**完成，越早越好。

## 四、关键动作：网站必须搬到国内服务器

这一步最容易被忽略：**Cloudflare Pages（pages.dev）不能承载备案域名。**
备案是绑定「接入商 + 境内 IP」的，所以备案域名必须解析到国内服务器；继续用 pages.dev 会导致备案被注销。

操作顺序（按你的 ECS 写好了）：

1. 阿里云控制台 → ECS 安全组，放行 **80 / 443**（22 保持开放给你 SSH）。
2. SSH 登录 ECS，装环境：

   ```bash
   sudo apt update
   sudo apt install -y nginx git
   sudo systemctl enable --now nginx
   ```

3. 拉代码到站点目录：

   ```bash
   sudo mkdir -p /var/www/redwenzi
   sudo git clone https://github.com/redwenzi101/redwenzi-blog.git /var/www/redwenzi
   ```

4. 签 HTTPS 证书（certbot 会自动改 Nginx 并加 80→443 跳转）：

   ```bash
   sudo apt install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d redwenzi.icu -d www.redwenzi.icu --redirect --agree-tos -m 1658229516@qq.com
   ```

5. 套配置模板：把仓库里的 `deploy/nginx.conf` 复制到 `/etc/nginx/conf.d/redwenzi.conf`，
   把 `example.com` 改成 `redwenzi.icu`、`/var/www/example` 改成 `/var/www/redwenzi`，然后：

   ```bash
   sudo nginx -t && sudo systemctl reload nginx
   ```

6. DNS（DNSPod）：`redwenzi.icu` 和 `www` 各加一条 **A 记录**指向 ECS 公网 IP。
   如果要用 `www`，也可以给主域名加一条 CNAME 指向 `www`；两条都指 A 记录最省事。

7. 备案域名不要解析到境外：确认没有别的 A 记录指向 Cloudflare 的 IP（否则会有被注销备案的风险）。

8. 验收：

   - `https://redwenzi.icu` 能打开，`http://` 自动跳 `https://`
   - `https://www.redwenzi.icu` 也能打开
   - 手机上用流量（不连 WiFi）也能打开

9. 以后更新：服务器上执行 `bash /var/www/redwenzi/deploy/update-site.sh`，或在 `crontab` 里加定时拉取。

## 五、把写死的旧域名换掉

站点里目前有 **57 处**写死的 `https://redwenzi-blog.pages.dev`（`feed.xml` 56 处 + 一篇文章里 1 处）。
不换的话 RSS 订阅者点开还是旧地址。换法：

```powershell
pwsh tools/site-config.ps1 -Domain "你的域名.com"
```

两个都要改就一起跑：

```powershell
pwsh tools/site-config.ps1 -Icp "浙ICP备2026000000号-1" -Domain "你的域名.com"
```

## 六、内容合规自查（个人备案尤其注意）

- 个人备案网站**不得有经营性内容**：广告位、带货、付费专栏、募捐都不行。
- 个人备案通常**不允许论坛 / 评论 / 注册登录**这类互动服务。你之前计划接 Giscus 评论，建议先别上；想留反馈入口可以写成「邮件联系」。
- 页面上不要出现未经授权使用的第三方 logo、图片、字体。
- 站内讲的第三方品牌、产品名属于正常指代，但别做成「官方合作」的观感。
- 备案主体信息（姓名、证件、手机号）如果变了，要在 **30 日内做变更备案**。

## 七、长期维护

- 换服务器、换接入商、换域名、换主体 → 都要做「变更备案」。
- 备案信息每年会被核验，留给工信部的手机号要保持可接通。
- Cloudflare Pages 可以继续留作**预览站**（pages.dev 那个地址），但备案域名不要同时解析到境外服务器。
