用 AI 的几种方式：App / 命令行 / API / 中转站

red wenzi · 2026-09-10 · AI · 操作教程
本文讲“有哪几条路能用上 AI、每条怎么接”。概念（API / Token / 模型等）见📚知识大全。
🇨🇳 大陆使用提示：优先选国内能直接访问的服务——DeepSeek、通义千问、智谱 GLM、Kimi 等（App 或 API 都能用），或本地模型 / 中转站；OpenAI、Claude 官方在大陆需要代理，通常不是首选。静态托管若选 pages.dev / vercel.app，国内访问可能偏慢。

先看总表：五条路

方式典型工具要准备什么适合谁
① 官方网页 / AppChatGPT、Claude、DeepSeek 官网/客户端注册账号（可免费额度）所有人，零门槛
② 第三方客户端Chatbox、Cherry Studio、LM Studio一个 API Key 或本地模型想一个界面用多家模型
③ 命令行aichat、各家 CLI、Ollama CLI环境变量里的 Key开发者 / 终端党
④ 代码 / APIPython + openai 库Key + 接口地址写程序、做自动化
⑤ 本地模型Ollama、LM Studio、vLLM一台有内存/显卡的电脑要隐私、要免费、爱折腾

方式 ① 官方网页 / App（最省事）

  1. 打开官网（或手机应用商店）注册账号。
  2. 用免费额度直接聊；不够再订阅或按量充值。
  3. 重要数据、隐私内容先想清楚再发——网页对话会送到厂商服务器。

方式 ② 第三方客户端（一个界面用多家模型）

Chatbox / Cherry Studio 这类桌面客户端支持“OpenAI 兼容接口”，等于把各家模型装进一个聊天窗。接法三步：

  1. 先在厂商/中转站拿到 接口地址(base_url) + API Key。
  2. 客户端设置里新建“自定义服务”，填：接口地址、Key、默认模型名。
  3. 保存后像普通聊天软件一样用；模型名改一行就能切换。

不想花钱就用 LM Studio：它能在本机跑模型，界面和客户端一样，不需要 Key。

方式 ③ 命令行（终端里直接问）

先存 Key，再装一个命令行客户端：

# PowerShell
$env:OPENAI_API_KEY = "sk-你的key"
# macOS / Linux / Git Bash
export OPENAI_API_KEY="sk-你的key"
# 安装 aichat（示例）
curl -sSf https://raw.githubusercontent.com/sigoden/aichat/main/install.sh | sh

# 在终端直接问
aichat "用一句话解释什么是 API"

命令行工具通常会读环境变量；要连本地模型就把它指向 Ollama 的地址（见下文方式⑤）。

方式 ④ 代码 / API（把 AI 接进自己的程序）

pip install openai
from openai import OpenAI

client = OpenAI()  # 读环境变量 OPENAI_API_KEY
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)

三个关键值：base_url（接口地址）、api_key（钥匙）、model（模型名）。它们决定你走哪条通道：

通道base_urlapi_key说明
官方 API官方给的地址官方控制台创建最稳、最正规，直接对接模型厂商
中转站中转站给的地址中转站买的 Key聚合多家模型 / 方便国内支付，但有风险
本地模型http://localhost:11434/v1随意填免费、私密，吃自己电脑配置

Key、Token 和“中转站”到底怎么回事

官方 API

在模型厂商官网注册 → 绑定支付方式 → 创建 API Key。计费按 Token：费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价。长对话、长文档烧钱最快。

中转站（API 转发/聚合）

第三方把多家官方 API 聚合起来，给你一个统一的 OpenAI 兼容地址。对用户的好处：一个 Key 用多家模型、支付方便（常支持微信/支付宝）、国内访问更稳。接法就是把客户端/代码里的 base_url 换成中转站的地址。

⚠️ 中转站风险：可能跑路、吞余额、记录你的请求内容、甚至盗用 Key。规则：小额充值、只放“丢了也不心疼”的额度、别往里传隐私/机密；能走官方就走官方。

本地模型

免费、离线、数据不出门，代价是模型能力和速度受限于你的电脑。入门命令：ollama run qwen2.5:3b，然后它会给一个 http://localhost:11434/v1 的兼容地址，客户端和代码都能直接用。

实操检查清单

  • 网页用：账号密码就能上，先分清“免费额度”和“会员”。
  • 客户端用：三样必填——base_url、api_key、model；填完先发一句“你好”测试。
  • 命令行用：Key 放环境变量，别写进脚本再提交 Git。
  • 程序用：把 Key 放环境变量 / 配置文件（.env），加进 .gitignore。
  • 中转站用：小额试水 → 稳定再考虑；敏感数据一律不传。
  • Token 超支：给账号设额度上限，养成看用量习惯。
