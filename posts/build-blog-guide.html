博客搭建指南：从域名到上线

red wenzi · 2026-09-10 · 技术

这篇文章把「域名」和「服务器」两件事串起来，记录我把 example.com 博客从零搭到可以上线的心路历程，也当一份给新手的指南。

一、域名是什么

域名就是网站的“门牌号”，比如 example.com。它本身不存内容，只负责指向一台真正的服务器。这套“指路”机制叫 DNS（域名系统）。

你在域名注册商那里买了域名后，要做两件事：

  1. 实名认证：国内注册的域名（尤其是备案时）必须完成实名。
  2. 解析（DNS 记录）：把域名指向服务器 IP，最常用的是 A 记录。
example.com  A  1.2.3.4          # 换成你自己的公网 IP
www          A  1.2.3.4          # 让 www 也指向同一个 IP
常见坑：主域名指向了服务器，但 www 或子域名没配、或配错 IP，导致网站时好时坏。建议所有 A 记录严格一致。

二、选购服务器

博客需要一台 24 小时在线的“主机”。国内主流是阿里云 / 腾讯云的 ECS 或轻量应用服务器，选择时注意三点：

  • 地域：机房在中国大陆才能备案；香港/海外不用备案，但访问稍慢。
  • 计费：备案要求包年包月且购买时长≥3 个月，按量付费不能备案。
  • 带宽：个人博客 1~3 Mbps 够用，重点是稳定。

我选的是阿里云青岛机房的 Ubuntu 22.04 实例。拿到公网 IP 后，记住顺序：先放行安全组端口，再登录系统。

三、备案（中国大陆必须）

备案是工信部对网站主体和所在地的登记。几个要点：

  • 遵循“谁接入谁备案”：服务器在哪家云，就在哪家备案，跟域名注册商无关。
  • 域名注册在腾讯云没关系，服务器在阿里云，就得去阿里云备案系统提交。
  • 备案期间：不要用域名对外提供网站服务，否则可能导致备案被退回。

流程：填主体信息（个人/企业）→ 填网站信息 → 上传证件 + 人脸核验 → 云厂商初审 → 管局终审（1~20 工作日）→ 拿到 ICP 备案号，上线后 15 天内挂到网站页脚并链接到 beian.miit.gov.cn。

我开始在腾讯云提交备案，结果提示“无满足备案条件的云服务器”——因为我根本没有腾讯云服务器，得换到阿里云做。这就是“谁接入谁备案”的坑。

四、在服务器上装环境

博客程序我用的是最主流的 WordPress（PHP + MySQL）。登录服务器（SSH 或云厂商网页版终端）后，按下面装：

sudo apt update && sudo apt upgrade -y
sudo apt install -y nginx mariadb-server php8.1-fpm php8.1-mysql \
  php8.1-curl php8.1-gd php8.1-mbstring php8.1-xml php8.1-zip php8.1-intl curl

创建数据库

sudo mysql
CREATE DATABASE blog DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'wpuser'@'localhost' IDENTIFIED BY '你的强密码';
GRANT ALL PRIVILEGES ON blog.* TO 'wpuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

下载 WordPress 并配置 Nginx

sudo mkdir -p /var/www/example
cd /var/www/example
sudo curl -LO https://wordpress.org/latest.tar.gz
sudo tar -xzf latest.tar.gz --strip-components=1
sudo rm latest.tar.gz
sudo chown -R www-data:www-data /var/www/example

写一个 Nginx 站点配置（/etc/nginx/sites-available/redwenzi）：

server {
    listen 80;
    server_name example.com www.example.com;
    root /var/www/example;
    index index.php index.html;
    location / { try_files $uri $uri/ /index.php?$args; }
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.1-fpm.sock;
    }
}
sudo ln -s /etc/nginx/sites-available/redwenzi /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

五、上线与 HTTPS

备案通过后，启动网站并申请免费证书：

sudo systemctl enable --now nginx
sudo certbot --nginx -d example.com -d www.example.com --redirect --agree-tos

然后浏览器打开 https://example.com，按提示填数据库信息完成安装，就能正式写文章了。

六、必要的安全与维护

  • 云厂商安全组只放行 22（SSH）、80（HTTP）、443（HTTPS），千万别开放 3306（数据库）。
  • 给 root/数据库设强密码，定期备份数据库和网站目录。
  • 用 apt-get upgrade 和 WordPress 后台及时打安全补丁。

从买域名、配解析、买服务器、换备案，到装环境、上线、加 HTTPS，一步步折腾下来，我的博客终于要“活”了。希望这份指南也能帮到想把博客搭起来的你。
