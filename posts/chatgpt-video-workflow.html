🎯 你会看到：Sora 关停后还剩哪些能力、怎么把 ChatGPT 当视频前期的中枢、一套我在用的七步流程、可以直接复制的提示词模板，以及怎么用插件和技能把每次都重复的那几遍固定下来。
⚠️ 先说结论：ChatGPT 现在已经不能直接生成视频。Sora 网页版与 App 在 2026-04-26 关停，Sora API 在 2026-09-24 关停。网上还在教“一句话出片”的教程都过期了。我以前的Sora作品，是用官方导出入口 sora.chatgpt.com/sunset 导出来的，导出窗口结束后数据会被永久删除。

一、先划清边界：什么能做，什么不能做

把边界划清楚，能省下大量试错时间。下面这张表是按我自己做视频时的动作整理的：

任务现在能不能做说明 / 替代做法
文字生成视频不能Sora 已关停，改用自备的第三方视频工具
图片生成视频不能但可以用 ChatGPT 生成关键帧，再交给视频工具
上传视频让 ChatGPT 分析不建议依赖官方上传支持文档/表格/演示，未包含视频；可先导出关键帧截图
生成图片与关键帧可以ChatGPT Images 支持文生图、图生图、局部重绘、指定宽高比
写脚本、分镜、镜头提示词可以，是强项目前投入产出比最高的一环
写配音稿与字幕可以可同时给时间轴估算、停顿位置与断句建议
批量处理与剪辑指令可以（在 Codex 里）生成 ffmpeg 命令或脚本，做拼接、压缩、多尺寸导出

换句话说：成像那一步得靠别的工具，但一条片子最耗时间的部分——选题、脚本、分镜、提示词、配音稿、字幕、剪辑节奏——都能交给 ChatGPT。

二、让效果更好的五个做法

1. 别用一句话，用一张分镜表

“做一个关于咖啡的短视频”这种需求，模型只能自由发挥，结果不可控。把它拆成镜号、时长、画面、景别、运镜、光线、字幕、音效之后，你对成片的控制力会立刻上一个台阶，而且这张表可以直接当视频工具的逐镜输入。

2. 先定风格锚点，再写镜头

风格锚点是一组固定的描述词，比如“35mm 胶片质感、低饱和青橙调、手持轻微晃动、黄昏侧逆光”。先让 ChatGPT 定 5～8 条锁死，后面每个镜头都原样复述。风格漂移通常不是模型不行，而是你每次描述都在变。

3. 先用静帧锁画面，再出视频

生成图片比生成视频便宜、快、可控。先给每个镜头做一张关键帧，确认构图、配色、造型，再去做图生视频。不满意就改图，别反复重抽视频。

4. 一次只改一个变量

重抽的时候如果同时改了运镜、光线和场景，你根本不知道是哪一处起了作用。固定其他条件，每次只动一项，并给提示词标版本号。两三轮就能摸出一套稳定配方。

5. 分工要清楚

你负责判断和取舍，ChatGPT 负责给结构化方案和备选，视频工具负责成像。把“这个镜头不够高级”换成“保持构图，光比提高、背景虚化加深、人物视线看向画外”，修改才会真的生效。

三、我在用的七步流程

1写项目简报

先用一段话讲清用途、时长、投放平台、目标受众、必须出现和绝对不能出现的内容，让 ChatGPT 整理成简报并逐条跟你确认。五分钟的事，能省掉后面好几轮返工。

2出脚本和分镜表

先要三个方向差异明显的创意，选定一个再展开成完整分镜表。字段建议固定成：镜号、时长、画面内容、景别、运镜、光线与色调、字幕或旁白、音效。

3生成关键帧

打开 ChatGPT 侧边栏的 Images，或直接在对话里描述画面。做四件事：锁风格锚点；每个镜号出一张 16:9 或 9:16 的关键帧；用编辑器圈选局部修改，别整张重画；按镜号命名存好，后面要上传给视频工具。

4转成视频工具能读懂的提示词

把分镜表逐行改写成视频提示词，每条包含五个要素：主体与动作、镜头语言、光线与色调、风格锚点、时长与音频。一次只提交一个镜头，别把整张表塞进一段提示词。支持首尾帧的工具，就把相邻两张关键帧分别当首帧和尾帧。

5配音、字幕、音乐

让 ChatGPT 按成片节奏写配音稿，标出停顿位置和推荐语速，再基于最终配音生成字幕并断句。音乐只需要说情绪曲线，比如“前五秒克制，中段推进，结尾留白”。

6剪辑与合成

这一段的重复劳动最多：拼接、统一分辨率帧率、压体积、烧字幕、导出横竖两版。我把素材目录交给 Codex，让它生成并执行批量脚本，先在样片上验证，再跑全片。

7复盘归档

把最终提示词、参数和踩过的坑写回素材库，标出哪些写法有效。下次做同类视频直接复用，不用从零开始。

环节和工具怎么配

工具没有唯一答案，能稳定出片的就是好工具。下面是我目前的搭配，功能与额度请以各家官网为准：

环节我用什么说明
剧本与提示词ChatGPT 或同类模型出简报、创意、分镜与逐镜提示词，全流程中枢
关键帧图像ChatGPT Images成本最低的试错方式，先定画面再做视频
视频生成即梦这类工具文生视频、图生视频，需要自备账号与额度
后期与合成Phantom Editor、剪映一类拼接、调色、字幕、音效与特效
批量与导出Codex统一规格、压缩、批量改名、多尺寸导出

四、动画能省，真人不能省

这是我自己踩过的坑：同样的流程，动画和真人的容错率完全不一样，路线应该分开。判断标准只有一条——观众对瑕疵的容忍度。

题材推荐路线为什么
动画、卡通、风格化可以先用成本更低的模型批量出稿，再让 agent 批量处理画面本身是抽象的，容错高，适合快速试错和大量变体
真人、写实、口播、产品不建议换低成本模型，走 agent 编排加质量更高的视频工具人像和产品细节容错极低，出问题的镜头基本补不回来
动画 + 真人混合交给 agent 把两段拆开做，最后合成动画段落跑低成本路线，真人段落走高质量路线

所以准确的说法不是“能不能换模型”，而是“这一段能不能换”。把容忍度低的段落单独标出来，交给更强的模型或工具，其余部分再去省成本。真人题材我更推荐用 agent 来编排：拆镜头、写提示词、逐条生成和检查，而不是让一个便宜模型一口气交全片。

五、可以直接抄的提示词模板

方括号里换成你的项目信息。建议在同一条对话里连着用，让 ChatGPT 保留上下文。

① 项目简报

你是短视频项目的前期策划。请把我下面的想法整理成一份项目简报，包含：目标受众、
核心信息、成片时长、投放平台、必现元素、禁忌元素、交付格式。整理完后列出三个需要
我确认的问题，等我确认再继续。
我的想法：[一句话描述]

② 创意方向与分镜表

基于上面的项目简报，先给我三个差异明显的创意方向，每个方向用三句话说明，等我选定一个。
选定后，请输出完整分镜表，使用表格，字段为：镜号、时长、画面内容、景别、运镜、光线与
色调、字幕或旁白、音效。要求：总时长 [xx] 秒；单镜头不超过 5 秒；所有镜头共用同一组风
格锚点，并在表格上方先列出这组锚点。

③ 关键帧图像

生成第 [03] 号镜头的关键帧。画面：[人物或物体与动作]。构图与景别：[特写或中景]。
镜头：[视角与焦段]。光线：[方向与质感]。风格锚点：[完整复述那一组锚点]。
宽高比：[16:9]。画面中不要出现文字和水印。

④ 视频提示词与首尾帧

把第 [03] 号镜头改写成视频生成提示词，按这个顺序写：主体与动作、镜头运动、光线与色调、
风格锚点、时长与音频、负向要求，整体控制在 120 字以内。如有首尾帧，请分别说明首帧与
尾帧的画面差异，并描述中间的过渡动作。

⑤ 配音稿与字幕

根据最终分镜表写配音稿，每段不超过 [xx] 字，用斜杠标注停顿，并给出推荐语速。
随后基于配音稿输出字幕文本，每行不超过 14 字，按语义断句，并标注对应的镜号。

六、工作流、插件与技能：把重复的那几遍省掉

我做视频最大的痛点是：每次都要重复交代好几遍才能出好效果。后来想明白了——不是模型笨，是那些要求只存在我脑子里，没有被写进工作流。

工作流：给干活的 agent 一本手册

工作流就是把重复出现的环节写成固定步骤：输入什么、按什么顺序处理、输出什么格式、哪一步需要人确认。固定下来的好处很直接：产出格式一致，换人接手也能对上；同类项目能复用同一套模板；出问题能定位到具体环节，不用整条链路推倒重来。

插件和技能，不是一回事

对比项插件 Plugin技能 Skill
是什么能力的打包单位可复用的工作流说明
能装什么技能、连接的应用、应用模板指令、示例、代码
要连账号吗看是否包含需要授权的应用不需要
主要解决让 ChatGPT 触达外部数据与工具让产出的格式与流程保持稳定
怎么用装好后用 @ 提及或加号菜单调用装好后由 ChatGPT 自动调用

在 ChatGPT 里装插件

  1. 侧边栏进入 Plugins，看插件的说明、包含的技能和需要的应用。
  2. 选择安装；如果要连应用，按提示登录对应账号。
  3. 用的时候在对话里 @ 提及，或点加号选 More。
  4. 团队/企业工作区里，能不能用还取决于管理员的权限设置，装插件本身不会绕过这些限制。

在 Codex 里用插件和技能

  1. 打开任务视图里的 Sources，选择使用插件。
  2. 搜索并选中已安装的插件。
  3. 技能会在合适的时候自动调用；本机或 Codex 专属插件可能需要先导入。
  4. 视频后期这类有明确步骤的重复工作最适合写成技能，比如固定的命名规则、导出规格、压缩参数。

写一个自己的技能：视频分镜助手

把下面这段直接发给 ChatGPT 的 skill-creator（技能页面里 Create → Create with chat），它会帮你生成正式文件、补示例并提示要确认的细节：

技能名称：视频分镜助手
适用场景：需要把一句创意变成可拍摄、可生成的分镜表时。
指令内容：
你是短视频分镜助手，按下面的顺序工作。
1. 先复述你对目标、时长、投放平台的理解，并列出三个需要我确认的问题。
2. 我确认后，给出三个差异明显的创意方向，等我选定其中一个。
3. 输出分镜表，字段固定为镜号、时长、画面内容、景别、运镜、光线与色调、字幕或旁白、音效。
4. 表格上方固定列出本次的风格锚点，共 6 条，覆盖色彩、光线、焦段、质感、节奏与氛围。
5. 每个镜头附一条可直接粘贴到视频生成工具的提示词。
6. 最后输出一份生成或拍摄顺序清单，标出哪些镜头可以复用同一张关键帧。

插件会互相打架，先筛选再装

我做特效时遇到过：特效类插件和 AI 增效类插件容易冲突，两者都想接管同一段画面或同一条时间线，表现就是渲染失败、效果被覆盖、导出卡住。后来按四条规矩处理就稳了：

  1. 一次只引入一类插件，特效类和增效类分不同项目启用。
  2. 先用一小段样片验证组合是否稳定，再跑全片。
  3. 记录每个项目实际生效的插件清单和版本。
  4. 出问题先禁用最近新增的那一个，而不是重装整套环境。

插件装得越多，能复现的稳定组合就越少。按项目维护一份最小插件集，比把目录塞满实用得多。

为什么总是要重复好几遍：六项一次配好

  • 固定术语：项目称呼、角色名、产品名、风格名统一写下来，别每次换说法。
  • 固定分镜字段：镜号、时长、画面、景别、运镜、光线、字幕、音效的顺序不要变。
  • 固定风格锚点：六条左右的描述词锁死，每次原样复述。
  • 固定输出格式：分镜表、视频提示词、字幕各存一份模板，直接调用。
  • 固定命名与归档：素材、关键帧、成片的命名规则和存放目录一次定好。
  • 固定检查清单：下面那一节做成清单，每次照着过一遍。

这些内容放进一个技能里，等于给干活的 agent 配了一本手册：你只需要说清这条片子要什么，流程、格式和检查项都不用再重复。这一条是我做视频以来省时间最多的地方。

七、导出前的检查清单

  • □ 核心信息在前三秒出现，没有错别字，专有名词和数字核对过。
  • □ 人物、产品、配色、光线在镜头之间没有跳变。
  • □ 手部和文字没有畸变，运动没有异常，转场没有明显的生成痕迹。
  • □ 配音和字幕对齐，背景音乐不压过解说，结尾有收束。
  • □ 分辨率、帧率、码率、宽高比符合投放平台要求。
  • □ 涉及真实人物、品牌、音乐、肖像的素材都有授权。
  • □ 横竖两版都导出了，封面、源文件、提示词都归档了。

八、常见问题

为什么不让模型直接出全片？

一次成片的可控性太低。模型一次生成的镜头越多，出了问题越难定位是哪句指令导致的。拆成镜头之后，每个环节都能单独重跑，成本和时间也更好控制。

便宜一点的模型到底能不能用？

看题材，不看价格。动画和风格化可以先跑低成本模型；真人、写实、口播、产品这类画面不建议为了省钱换模型。判断标准就是这一段出问题之后能不能补。

插件和技能是不是装得越多越好？

不是。插件越多，冲突概率越高，能复现的稳定组合越少。按项目维护最小集合，比把目录塞满可靠。

换成别的模型之后，之前写的东西会作废吗？

不会。提示词、分镜格式、流程步骤、检查清单都是独立于模型的资产，需要换的只有调用入口。把提示词和流程做成不依赖具体供应商的资产，判断一套工作流合不合格，就看它换模型之后还能不能接着跑。
