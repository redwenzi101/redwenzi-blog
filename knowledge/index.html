网络与建站基础

IP 地址IP address

互联网上每台设备的“门牌号”，一串数字，例如 1.2.3.4。IPv4 是常见的四位数字，IPv6 是更长的新版。

↑ 回目录

服务器Server

一台长期开机、有公网地址的电脑，负责接收请求并返回内容。可以是云服务器，也可以是家里的旧电脑（配合内网穿透）。

↑ 回目录

网站Website

运行在服务器上、通过浏览器访问的内容：前端（HTML/CSS/JS）+ 可选的后端与数据库。博客只是网站的一种。

↑ 回目录

域名Domain

IP 的“名字”，例如 example.com。需要按年付费注册并续费，通常还要实名认证。

↑ 回目录

网址URL

访问某个资源的完整地址，如 https://example.com/posts/a.html，由协议、域名、路径组成。

↑ 回目录

DNS / 解析Domain Name System

把域名翻译成 IP 的“通讯录”。你在域名服务商处配置的解析记录，决定这个域名指向哪里。

↑ 回目录

DNS 记录类型DNS Records

A（指向 IPv4）、AAAA（指向 IPv6）、CNAME（别名指向另一域名）、MX（邮件）、TXT（验证/SPF）。

↑ 回目录

端口Port

服务器上给不同服务用的“门”。网页常用 80（HTTP）与 443（HTTPS），远程登录用 22（SSH）。

↑ 回目录

SSHSecure Shell

远程安全登录服务器的协议。密码登录简单，密钥登录更安全；GitHub 推送代码也常用 SSH 密钥。

↑ 回目录

防火墙 / 安全组Firewall

控制哪些端口能被外部访问的“门卫”。云厂商的安全组只放行必要端口（如 22/80/443），数据库 3306 等不要对外开放。

↑ 回目录

ICP 备案ICP Filing

大陆服务器上的网站上线前，须在服务器所属云厂商处提交备案。“谁接入谁备案”，跟域名注册在哪家无关。备案通过前不要用域名建站。

↑ 回目录

HTTPS / SSL 证书Certificate

给网站加密的“锁”。安装证书后地址变成 https://，浏览器不再提示不安全。可用 Let's Encrypt / certbot 免费申请。

↑ 回目录

Nginx / 反向代理Reverse Proxy

最常用的 Web 服务器之一：接收外部请求，转发给后端程序（如 PHP-FPM），还能做 HTTPS、负载均衡。

↑ 回目录

WordPressCMS

最流行的建站程序（PHP 编写），带后台，主题插件多，适合博客和企业站。

↑ 回目录

数据库Database

用来存数据：文章、用户、评论。博客常用 MySQL/MariaDB，现代应用也常用 MongoDB 等。

↑ 回目录

免费托管Static Hosting

静态网站可托管在 GitHub Pages、Vercel、Netlify 等平台，免费且无需自己维护服务器；需要后端时才买服务器。

↑ 回目录

AI 与大模型

LLM 大语言模型Large Language Model

能理解并生成文字的人工智能模型，如 GPT、Claude、DeepSeek 等。它不会主动行动，只会根据输入生成输出。

↑ 回目录

TokenToken

模型计算文本的单位，约等于半个到一个汉字。它同时决定“计费”和“一次能记住多长”。

↑ 回目录

API 与 API KeyApplication Programming Interface

让程序调用模型能力的接口。用 API Key（密钥）认证调用；Key 相当于“钱 + 权限”，绝不能外泄或提交到 Git。

↑ 回目录

Prompt 提示词Prompt

你发给模型的指令文本。写好角色、目标、格式、示例，模型输出质量会明显提升，这就是 Prompt 工程。

↑ 回目录

上下文窗口Context Window

模型一次对话能“记住”的最大 Token 数。超出后需要精简内容、总结历史或用 RAG 检索。

↑ 回目录

RAG 检索增强生成Retrieval-Augmented Generation

先检索自己的资料库，把相关片段随问题一起交给模型，让模型能回答“没学过”的私有资料。

↑ 回目录

Embedding 向量Embedding

把文字变成一串数字（向量），语义相近的文字向量距离更近，RAG 检索和相似搜索都靠它。

↑ 回目录

Agent 智能体AI Agent

能自己规划步骤、调用工具、观察结果并继续执行直到完成任务的小程序，而不是一问一答的聊天。

↑ 回目录

Function Calling 工具调用Function Calling

模型输出“我要调用某个函数+参数”，由你的程序真正执行并把结果返回给模型，是 Agent 的关键机制。

↑ 回目录

微调Fine-tuning

用一批特定数据继续训练模型，让它更懂你的风格或业务。比 Prompt 重，一般先用 Prompt/RAG 就够了。

↑ 回目录

量化Quantization

压缩模型体积、降低显存占用以换取略低精度，让大模型能在个人电脑上跑（如 Q4 量化模型）。

↑ 回目录

推理Inference

模型“回答问题/生成内容”的过程叫推理，需要显存（VRAM）；高并发场景需要推理框架优化。

↑ 回目录

OllamaLocal Runner

一行命令即可在本地跑开源模型的工具，自带 OpenAI 兼容端点（localhost:11434），适合入门本地部署。

↑ 回目录

vLLMInference Engine

面向高并发的模型推理框架，吞吐高、显存利用好，适合在服务器上服务多个用户。

↑ 回目录

OpenAI 兼容 APICompatible Endpoint

许多服务（云厂商、Ollama、vLLM）都提供和 OpenAI 相同格式的接口，换一个 base_url 就能切换模型，代码几乎不用改。
