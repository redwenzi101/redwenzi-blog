Think Tank · 智库平台

red wenzi · 2026-09-10 · 项目
🔒 本项目的代码暂不公开（高校/团队项目），此处仅作项目介绍。如有合作或交流意向，欢迎联系我。

Think Tank 是一个面向高校院系的智库平台，用来做资讯发布、知识库管理、用户评论与讨论，让院系里的好内容能沉淀下来、被更多人看到。

核心功能

  • 资讯发布：管理员发布行业资讯与研究成果
  • 知识库：结构化整理，方便检索与学习
  • 用户系统：注册、登录与评论讨论
  • 权限管理：管理员可审核与管理内容

技术栈

Next.js 14 (App Router) Tailwind CSS MongoDB / Mongoose NextAuth.js Vercel

我在其中做的事

负责平台整体规划与关键模块实现，包括图片上传/访问/删除的统一接口设计，以及前后端联调、部署环境配置。这算是我第一个从规划到落地都比较完整的 Web 全栈项目。
